# Concept — idea, directions, naming

The generated system is consistent; the concept makes it *meaningful*. Do this in Full mode (and briefly in Lite).

## 1. Describe the logo literally
One sentence of what is actually there: shapes, how parts relate, colour logic, what is distinctive.
*(Example, fictional: "a compass kite split into a dark and a light half with one warm tip".)*

## 2. Brand idea (2–6 words)
Cross the logo's form with the company's purpose. The best ideas let every later decision be explained.
*(Fictional examples: a kite split in two halves → "Two views. One direction." · concentric rings → "Care that keeps you moving" ·
a badge with code brackets → "Learn by making.")*

## 3. Principle = X + Y
A precise thing + a human thing (e.g. STRUCTURE + WARMTH, PRECISION + PLAY). Every layout pairs them: grid + photography,
technical labels + hand-set headline, chamfered panel + soft image.

## 4. Root insight (optional)
A cultural, material or place truth that makes the identity specific (materials, craft, landscape, local typography) — used in
names and textures, never as cliché imagery. Avoid religious or political symbolism unless the brief asks for it.

## 5. Three directions → one
Write three short directions (name, core, risk), e.g. "Rigour" (grid, mono labels; risk: cold), "Warmth" (soft forms, serif;
risk: generic), "Signal" (one bold colour, big type; risk: loud). Choose or merge, and record what was rejected and why.
Show directions as boards only in Full mode (render with the foundations: same logo, different DNA overrides).

## 6. Naming
- **Colours**: rename auto names ("jade", "navy") after the root insight or the brand world — short, pronounceable, not cute.
- **Units / sub-brands** (areas, practices, collections, departments): one naming pattern; one colour family, not a rainbow; if
  the mark has parts, each unit may own a real part of the mark (never invent extra pieces).
- **Patterns and motifs**: names that describe the form (band-diagonal, orbit-ring), not marketing words.

## 7. Write it down
`brand.config.json → brand.brand_idea, brand.principle`, palette names; re-run `foundation.py --only tokens,core,board,docs`.
The production spec and the brand book pick it up.
